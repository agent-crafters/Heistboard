# Domain documentation

Heistboard is a single-context repository.

- Read root `CONTEXT.md` before work that names or changes product concepts and invariants.
- Read relevant records under `docs/adr/` before changing an architectural decision.
- Use glossary terms in code, tests, issues, and UI copy; surface conflicts instead of introducing synonyms.
- Record durable, costly, non-obvious trade-offs as ADRs. Keep temporary implementation facts in architecture or issue notes.
